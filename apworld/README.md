# apworld

Python. This is not a normal apworld, and if you came here from the
Archipelago community that matters, so it is the first thing said.

**The item and location tables are not written here.** They are generated from
`gamedata/`, a Go package, and committed as JSON under `tf2_mvm/data/`. This
directory holds the code that reads that JSON and the logic that cannot be
expressed as data. The reasoning is in [ADR
0001](../docs/adr/0001-go-owns-the-game-data.md).

## What goes here

`tf2_mvm/`, the apworld package:

- `__init__.py` — the `World` subclass. Builds the item pool and the location
  list from the exported JSON, constructs the region graph, sets access rules,
  declares the goal condition.
- `Options.py` — the YAML options. **Hand-written, not generated.** Option
  classes are code with docstrings that the Archipelago website renders as
  player-facing documentation, so they are not a table. Adapt them from
  ALPHAMARIOX's `Options.py`, which is the one complete file in that fork.
- `Rules.py` — access rules, once there are enough of them to move out of
  `__init__.py`.
- `data/*.json` — generated by `gamedata/`, committed. Do not hand-edit. CI
  fails if these differ from what the Go source produces.
- `docs/` — the setup guide and game info page Archipelago expects.

## The data contract

The exported JSON carries a format version. The apworld refuses to load a data
file whose version it does not recognise, rather than half-loading it and
generating a broken seed.

The game name string and the AP base id offset also come from the export.
They are not repeated here. ALPHAMARIOX's fork declares two different game
names in two files, which is exactly the failure this avoids.

## Building the `.apworld`

Zip `tf2_mvm/` with the committed `data/` inside it. That is why `data/` is
committed rather than gitignored: the result is a standalone artifact that
works on a machine with no Go toolchain.

## Upstream

Submitting this to `ArchipelagoMW/Archipelago` is explicitly out of scope for
v1 (`docs/spec.md`). A JSON-reading apworld may not be accepted as-is. Revisit
once it generates and has been played end to end.
